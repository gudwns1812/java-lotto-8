# java-lotto-precourse

# 로또 발매기

**로또 구매 후 결과에 따른 당첨금과 수익률 계산 서비스**

## 입출력 요구 사항

### **입력**

- 로또 구입 금액을 입력 받는다. 구입 금액은 1,000원 단위로 입력 받으며 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.

```
14000
```

- 당첨 번호를 입력 받는다. 번호는 쉼표(,)를 기준으로 구분한다.

```
1,2,3,4,5,6
```

- 보너스 번호를 입력 받는다.

```
7
```

### **출력**

- 발행한 로또 수량 및 번호를 출력한다. 로또 번호는 오름차순으로 정렬하여 보여준다.

```prolog
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
[7, 11, 16, 35, 36, 44]
[1, 8, 11, 31, 41, 42]
[13, 14, 16, 38, 42, 45]
[7, 11, 30, 40, 42, 43]
[2, 13, 22, 32, 38, 45]
[1, 3, 5, 14, 22, 45]
```

- 당첨 내역을 출력한다.

```
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
```

- 수익률은 소수점 둘째 자리에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)

```erlang
총 수익률은 62.5%입니다.
```

- 예외 상황 시 에러 문구를 출력해야 한다. 단, 에러 문구는 "[ERROR]"로 시작해야 한다.

```prolog
[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
```

## 주요 기능

### 입출력

- [x] 사용자로부터 로또 구매 금액을 입력받는다.
- [x] 당첨 번호와 보너스 번호를 입력받는다.
- [x] 사용자에게 총 로또 개수와 각 로또 번호를 오름차순으로 출력한다.
- [x] 수익률을 소수점 둘째 자리에서 반올림하여 출력한다.
- [x] 예외 상황 시 에러 문구를 출력한다.

### 어플리케이션

- [x] 에러 발생시 에러난 위치에서 입력을 다시 받는다.
- [x] 금액에 따라 로또 수량을 계산하여 수량만큼 로또를 발매한다.
- [x] 당첨 번호와 보너스 번호를 비교하여 각 로또의 등수를 계산하고 집계한다.
- [x] 각 등수에 맞는 당첨금 및 수익률을 계산한다.

### 예외 사항

- [x] 사용자의 로또 구매 금액이 1000원 단위로 나누어 떨어져야한다.
- [x] 로또 구매 금액은 0보다 커야한다.
- [x] 로또의 각 번호가 중복되면 안된다.
- [x] 당첨 번호와 보너스 번호가 전부 중복되면 안된다.
- [x] 입력이 형식에 맞지 않는 입력이면 안된다.
- [x] 당첨 번호 입력에서 ,가 맨 뒤에 오면 예외를 발생시켜야 한다.

```prolog
당첨 번호를 입력해 주세요.

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개

```
